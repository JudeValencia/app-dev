# Dark (2017–2020)

> *"The question is not **where**, but **when**."*

**Dark** is a German science-fiction thriller and the **first German-language original series** made by Netflix. It was created by *Baran bo Odar* and *Jantje Friese*.

## Plot (No Spoilers)

When two children go missing in the small German town of **Winden**, four families start uncovering secrets that span several generations. The search reveals a mystery connected to *time travel* and a cycle that repeats every **33 years**.

## Main Families

1. The Kahnwalds
2. The Nielsens
3. The Dopplers
4. The Tiedemanns

## Main Characters

- **Jonas Kahnwald** – played by Louis Hofmann
- **Martha Nielsen** – played by Lisa Vicari
- **Ulrich Nielsen** – played by Oliver Masucci
- **Charlotte Doppler** – played by Karoline Eichhorn

## Tip for New Viewers

Keep track of the family trees while watching. Here's the basic rule of the show:

```
Year + 33 = The next cycle
1953 + 33 = 1986
1986 + 33 = 2019
```
